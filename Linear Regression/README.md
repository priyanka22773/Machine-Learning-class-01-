# Linear Regression

This folder contains my learning and implementation of **Linear Regression**, a supervised machine learning algorithm used to predict continuous numerical values.

* Multiple Linear Regression
* Independent and Dependent Variables
* Best Fit Line
* Cost Function
* Mean Squared Error (MSE)
* R² Score
* Model Training and Prediction
* Model Evaluation
* Data Visualization

* NumPy
* Pandas
* Matplotlib
* Scikit-learn
